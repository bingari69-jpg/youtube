[데스크톱 고양이 설치 방법]

1. 이 폴더를 원하는 곳에 둡니다. (예: 바탕화면)
2. "고양이시작.bat" 을 더블클릭합니다.
   - Python이 없으면 다운로드 페이지가 열립니다. 설치할 때 "Add python.exe to PATH" 체크!
   - 설치 후 다시 "고양이시작.bat" 을 더블클릭합니다.
3. 화면 오른쪽 아래에 고양이가 나타납니다.

[대화 기능 켜기]
"고양이시작.bat" 을 메모장으로 열어서
   rem set ANTHROPIC_API_KEY=sk-ant-...
줄의 "rem " 을 지우고 본인 API 키를 넣고 저장합니다.

[종료]
고양이 우클릭 -> 종료, 또는 트레이 아이콘 우클릭 -> 종료
