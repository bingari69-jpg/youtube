# 데스크톱 고양이 (desktop-cat)

모니터 아래쪽에 사는 작은 검은 픽셀 고양이입니다. 이미지 파일 없이 코드 안의 격자로 그려집니다.

## 하는 일

| 동작 | 설명 |
|---|---|
| 돌아다니기 | 화면 아래(작업표시줄 위)를 천천히 걷고, 멈추고, 눈을 깜빡입니다. |
| 마우스 따라가기 | 커서가 움직이면 신난 표정으로 쫓아갑니다. 커서가 멈추면 관심을 잃습니다. |
| 키보드 점프 | 아무 키나 누르면 놀란 표정으로 점프합니다. 2초에 15번 넘게 치면 어지러워합니다. |
| 재우기 | 트레이 메뉴 또는 고양이 우클릭 → 재우기. 졸린 표정으로 앉아서 z를 띄웁니다. 3분간 입력이 없으면 스스로 잠듭니다. |
| 깨워서 대화 | 자는 고양이를 클릭하면 깨어나고 대화창이 열립니다. 답은 말풍선과 대화창 양쪽에 나옵니다. |
| 옮기기 | 드래그해서 옮길 수 있습니다. 놓으면 바닥으로 떨어집니다. |
| 트레이 | 마우스 따라가기 / 키보드 점프 켜고 끄기, 크기 변경, 대화 기억 지우기, 종료 |

표정은 참고 이미지와 같은 6종입니다: 기본, 웃음, 신남, 놀람, 어지러움, 졸림 (추가로 깜빡임).

## 설치와 실행 (Windows)

1. Python 3.10 이상 설치 (설치 시 "Add to PATH" 체크)
2. `설치.bat` 더블클릭 (PySide6, pynput, anthropic 설치)
3. `실행.bat` 더블클릭

macOS/Linux:

```bash
pip install -r requirements.txt
python cat.py
```

macOS는 전역 키보드 감지를 위해 "시스템 설정 → 개인정보 보호 → 손쉬운 사용"에서 터미널(또는 Python)을 허용해야 합니다. 허용하지 않으면 점프만 빠지고 나머지는 동작합니다.

## 대화 두뇌 고르기

`brain.py` 하나에 세 가지 백엔드가 있고, 환경변수로 고릅니다.

| 설정 | 동작 |
|---|---|
| `ANTHROPIC_API_KEY` 설정 | Claude API로 대화 (기본 모델 `claude-opus-5-5`, `CAT_MODEL`로 변경) |
| `CAT_BRAIN=ollama` | 로컬 Ollama 서버 사용. 모델은 `CAT_OLLAMA_MODEL` (기본 `llama3.2`) |
| 아무것도 없음 | "냐옹"만 하는 대체 두뇌. 나머지 기능은 전부 동작 |

Windows에서 키를 넣는 가장 쉬운 방법은 `실행.bat` 안의 `rem set ANTHROPIC_API_KEY=...` 줄에서 `rem`을 지우는 것입니다.

나중에 직접 학습시킨 모델을 붙이고 싶으면 `brain.py`에 `BaseBrain`을 상속한 클래스를 하나 추가하고 `make_brain`에서 골라주면 됩니다. `cat.py`는 손댈 필요가 없습니다.

## 기타 설정 (환경변수)

| 변수 | 기본값 | 의미 |
|---|---|---|
| `CAT_NAME` | 먹물 | 고양이 이름 |
| `CAT_SCALE` | 6 | 픽셀 1칸의 크기 (4 작게, 6 보통, 9 크게) |
| `CAT_AUTO_SLEEP_SEC` | 180 | 이 시간 동안 입력이 없으면 잠듦 |

## 파일 구성

- `cat.py` : 창, 상태 기계, 입력 처리, 트레이, 말풍선, 대화창
- `sprites.py` : 픽셀 격자와 표정 정의. 그림을 바꾸고 싶으면 여기만
- `brain.py` : 대화 백엔드 (Claude / Ollama / 대체)
