# 스턴트 대역 사무소 (프로토타입 v0.2)

인간 대포로 스턴트 대역을 날려 감독들의 주문을 해결하고, 번 돈으로 장비를 업그레이드하는 래그돌 + 타이쿤 웹게임 프로토타입.

## 실행
`index.html`을 브라우저로 열면 됩니다(빌드 불필요). 물리 엔진 Matter.js 0.19.0을 cdnjs에서 불러오므로 인터넷 연결이 필요합니다.

## 조작
- 조준: 화면을 뒤로 끌었다 놓기 (키보드: ↑↓ 각도, ←→ 힘, Space 발사)
- 비행 중 회전: ← → 또는 A/D (모바일: 화면 하단 ⟲ ⟳ 버튼)
- R 다시 찍기, P 리플레이, Esc 사무소로

## 들어 있는 것
- 의뢰 16개: 건초 착지 / 수박 파괴 / 유리창 관통 / 공중 2회전 / 종 울리기 / 풍선 터뜨리기 / 트램펄린 담장 넘기 / 래칫 백드래프트 / 앵글 밖 에어백 / 로켓 로드스터 착지 / 불붙은 채로 2초 / 불 고리 통과 / 코르크스크루 점프 / 캐논 롤 5회전 / 버스 8대 넘기 / 상자 파괴 + 수영장 입수
- 실제 영화 스턴트 기법에서 가져온 의뢰: 래칫(비행 중 한 번 케이블로 당겨 감속, Space/↓), 전신 화상(2초 안에 물탱크로 소화), 캐논 롤(차를 정확히 5바퀴 굴린 뒤 바퀴로 서기, 8회 이상은 숨은 보너스), 코르크스크루 점프(공중 정확히 1회전 후 착지 램프에 바퀴부터), 앵글 밖 에어백(카메라 프레임을 지나 프레임 밖 작은 에어백에 착지)
- 로켓 로드스터: 차를 쏘고 ↑(W)로 추진기 분사(가스 5초), ← →로 자세 제어. 옥상 착지대에 충격 속도 6 이하, 바퀴가 아래로 향하게 착지하면 성공. 실제 상표는 쓰지 않은 가상 차량
- 별 3개 평가, 출연료·보너스·병원비 정산, 별 개수에 따른 의뢰 해금
- 업그레이드 5종: 발사대 출력, 공중 제어, 보호 패드, 매니저, 조준 보조. 언제든 산 값 그대로 반납(환불) 가능
- 슬로모션 리플레이: 결과창의 ▶ 버튼 또는 P. 파괴·입수·종 순간에 자동으로 0.25배속 + 줌인, 클릭/Esc로 건너뛰기
- 진행 상황은 브라우저 localStorage에 저장
