# 스턴트 대역 사무소 (프로토타입 v0.2)

인간 대포로 스턴트 대역을 날려 감독들의 주문을 해결하고, 번 돈으로 장비를 업그레이드하는 래그돌 + 타이쿤 웹게임 프로토타입.

## 실행
`index.html`을 브라우저로 열면 됩니다(빌드 불필요). 물리 엔진 Matter.js 0.19.0을 cdnjs에서 불러오므로 인터넷 연결이 필요합니다.

## 조작
- 조준: 화면을 뒤로 끌었다 놓기 (키보드: ↑↓ 각도, ←→ 힘, Space 발사)
- 비행 중 회전: ← → 또는 A/D (모바일: 화면 하단 ⟲ ⟳ 버튼)
- R 다시 찍기, P 리플레이, Esc 사무소로

## 들어 있는 것
- 의뢰 19개: 건초 착지 / 수박 파괴 / 유리창 관통 / 공중 2회전 / 종 울리기 / 풍선 터뜨리기 / 에어 램 3단 점프 / 트램펄린 담장 넘기 / 래칫 백드래프트 / 앵글 밖 에어백 / 폴 캣 스윙 / 로켓 로드스터 착지 / 불붙은 채로 2초 / 전구 전선 미끄럼 / 불 고리 통과 / 코르크스크루 점프 / 캐논 롤 5회전 / 버스 8대 넘기 / 상자 파괴 + 수영장 입수
- 실제 영화 스턴트 기법에서 가져온 의뢰: 래칫(비행 중 한 번 케이블로 당겨 감속, Space/↓), 전신 화상(2초 안에 물탱크로 소화), 캐논 롤(차를 정확히 5바퀴 굴린 뒤 바퀴로 서기, 8회 이상은 숨은 보너스), 코르크스크루 점프(공중 정확히 1회전 후 착지 램프에 바퀴부터), 앵글 밖 에어백(카메라 프레임을 지나 프레임 밖 작은 에어백에 착지), 에어 램(발판에 떨어지면 정해진 방향으로 발사), 폴 캣 스윙(장대 끝을 잡고 ← →로 반동, Space/↓로 놓기), 전구 전선 미끄럼(전선에 매달려 전구를 깨고 유리 지붕은 피해서 착지)
- 로켓 로드스터: 차를 쏘고 ↑(W)로 추진기 분사(가스 5초), ← →로 자세 제어. 옥상 착지대에 충격 속도 6 이하, 바퀴가 아래로 향하게 착지하면 성공. 실제 상표는 쓰지 않은 가상 차량
- 별 3개 평가, 출연료·보너스·병원비 정산, 별 개수에 따른 의뢰 해금
- 테스트 모드(기본 켜짐): 별 개수와 상관없이 모든 의뢰 열기 + 테스트 자금 +$1,000 버튼. 사무소 상단 체크박스로 끄면 원래 해금 규칙
- 사무소 의뢰 목록은 장르별 탭 4개(맨몸 액션 / 리깅·장치 / 화염 / 차량). 탭마다 완료 수와 새로 찍을 수 있는 의뢰 수 표시, 마지막 탭 기억
- 업그레이드 5종: 발사대 출력, 공중 제어, 보호 패드, 매니저, 조준 보조. 언제든 산 값 그대로 반납(환불) 가능
- 슬로모션 리플레이: 결과창의 ▶ 버튼 또는 P. 파괴·입수·종 순간에 자동으로 0.25배속 + 줌인, 클릭/Esc로 건너뛰기
- 진행 상황은 브라우저 localStorage에 저장
