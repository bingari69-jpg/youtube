# XENICS Cat 설계 요약

목표: 기능 많은 데스크톱 펫이 아니라 "조용히 옆에 있어 주는 존재". 사무실 사용자에게 위안을 준다.
전체 설계안(표, 근거, 일정)은 Claude 문서 "디지털 반려묘 앱 설계안"에 있다.

## 위안의 네 원리
존재(가만히 있어도 살아 있음) · 알아봄(오래 앉음, 늦은 밤을 눈치챔) · 무요구(페널티 없음) · 의식(아침 인사, 퇴근 의식, 쓰다듬기)

## 1차 범위 (이 폴더)
- 존재감: 숨 쉬기, 깜빡임, 그루밍, 식빵, 기지개, 하품, 둘러보기, 꼬리, 느린 산책, 느린 마우스 따라오기
- 교감: 문질러 쓰다듬기, 클릭해 말 걸기(규칙 대화 + 기분 토로 3마디 흐름), 재우기/깨우기
- 성장: 아기→어린이→청소년→어른. 친밀도와 함께한 날이 둘 다 차야 승급. 크기와 말투 변화
- 말 걸기: 시간대별 하루 1회 + 가벼운 응원. 하루 상한(자주 6/보통 4/가끔 2/끄기), 조용한 시간
- 스트레칭 알림: 연속 활동 50분(설정)
- 회의 모드: 앞 창이 전체화면이면 숨음. 수동 숨기기 1시간/3시간/하루
- 퇴근 의식: 설정 시각에 "오늘 한 일 하나만" 카드. journal.txt. 금요일엔 주간 목록
- 소식: notices.json + 정적 https 주소. 하루 1건, 같은 id 1회
- 업데이트: 정적 version.json 확인, 강제 없음

## 뺀 것과 이유
전역 키보드 훅(키로거로 보임 → GetLastInputInfo로 대체), 키 점프, 뉴스/환율/CPU, 음악 내장, Claude 직접 호출, 쥐 잡기/메모/일정(2차)

## 기술
- .NET Framework 4.8 + WinForms. Windows 10/11에 런타임 내장 → 설치 0, exe 수백 KB
- 픽셀 단위 투명 레이어드 창(UpdateLayeredWindow), 투명 영역은 클릭 통과(WM_NCHITTEST)
- 관리자 권한 불필요. 데이터는 %LOCALAPPDATA%\XenicsCat
- 리눅스/맥에서도 `dotnet build` 가능 (EnableWindowsTargeting + 참조 어셈블리)

## 배포 전 할 일
- 회사 코드 서명 (SmartScreen 경고 제거)
- 디자이너 스프라이트로 교체 (Sprites.Render 하나만 바꾸면 됨)
- 보안팀용 한 장 문서 (README.txt의 개인정보 절을 기반으로)
- 말 걸기 빈도와 성장 속도는 사용자 반응 보고 조정

## 2차 후보
숨 고르기(1분 호흡), 감정 체크인, 꾸미기 보상(브랜드 소품), 메모·일정, 쥐 잡기, 소리(골골), 회사 중계 서버를 통한 AI 대화
