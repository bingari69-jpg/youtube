XENICS Cat (먹물) v1.0.0
=========================

모니터 위에 사는 작은 픽셀 고양이. 사무실에서 지친 당신 옆에 조용히 있어 줍니다.

설치
  설치가 없습니다. XenicsCat.exe 를 더블클릭하면 끝. (Windows 10/11, 추가 설치 없음)
  시작할 때 자동 실행하려면: Win+R → shell:startup → 열린 폴더에 XenicsCat.exe 바로가기 넣기

사용법
  고양이 클릭           말 걸기 (한 줄 입력)
  고양이 위에서 문지르기 쓰다듬기 (마우스를 좌우로 왔다갔다)
  고양이 드래그         옮기기
  고양이 우클릭         메뉴 (재우기, 숨기기, 말 걸기 빈도, 스트레칭 알림, 퇴근 의식, 크기, 성장 상태, 종료)
  트레이 아이콘         같은 메뉴

고양이가 하는 일
  - 가만히 있을 때도 숨 쉬고, 깜빡이고, 그루밍하고, 식빵을 굽고, 기지개를 켭니다
  - 오래 앉아 있으면 (기본 50분) 일어나라고 합니다
  - 월요일 아침, 점심, 오후 슬럼프, 퇴근 무렵, 불금, 늦은 밤에 한마디씩 (하루 몇 번으로 제한)
  - 퇴근 시각(기본 18시)에 "오늘 한 일 하나만" 카드를 냅니다. 금요일엔 이번 주 목록을 보여줍니다
  - 전체화면 앱(발표, 영상, 게임)이 뜨면 스스로 숨고, 끝나면 돌아옵니다
  - 아기 고양이로 시작해 함께한 날과 교감에 따라 어린이, 청소년, 어른으로 자랍니다
  - "나 꿀꿀해" 같은 말에는 몇 마디 이어서 들어줍니다

개인정보와 보안
  - 키보드 입력 내용을 읽지 않습니다. Windows가 알려주는 "마지막 입력 시각"만 봅니다
  - 화면을 보지 않습니다. "앞 창이 전체화면인지"만 봅니다
  - 모든 데이터는 %LOCALAPPDATA%\XenicsCat 에만 저장됩니다
  - 외부 통신은 소식(notices.json 주소)과 업데이트 확인뿐이며, 둘 다 설정하지 않으면 통신이 없습니다

설정 파일: %LOCALAPPDATA%\XenicsCat\settings.json
  "NoticeUrl": "https://..." 소식 json 주소 (선택)
  "UpdateUrl": "https://..." {"version":"1.1.0","url":"https://..."} 형식 (선택)
  "QuietFrom": 9, "QuietTo": 12  이 시간엔 말을 걸지 않음 (선택)
